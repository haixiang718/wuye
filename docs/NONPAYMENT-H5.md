# H5 非支付流程完善

2026-11-03。范围为当前公众号 H5，真实微信支付保持关闭。

## 已修复

- 多房产快速切换时，旧房屋的慢响应可能覆盖当前房屋费用。现在用请求序号和房屋标识核对响应，旧响应和旧错误均不影响当前房屋。
- 房屋查询失败、业主信息接口返回错误或数据形态异常时，原 Promise 可能一直等待或出现未处理异常。现在向调用页明确返回失败，清空旧列表并提示重试；空费用显示无数据状态。
- 共享请求工具原来将请求头合并到字面量 `key`，并覆盖调用者的 POST 完成回调。现按真实头名称合并，加载结束后保留原完成回调。
- 账号登录不再将任意 HTTP 200 视为成功；明确处理业务拒绝、缺失业主/凭据和网络失败，登录页面接收失败后保留输入供重试。
- 服务端返回 401 时清理过期登录和业主缓存，并重新发起微信授权。同批旧凭据只触发一次，旧请求不清除新登录的凭据。本地会话过期时也会完成等待中的失败回调。
- 从房屋费用列表或欠费页因过期进入登录，登录成功后返回原房屋页面。只保存两条允许的本地路由及 roomId，丢弃 OAuth 凭据，30 分钟有效、使用一次即清除。目标房屋仍须由后端校验归属。
- H5 短信能力默认关闭；短信未开通时隐藏短信登录及注册验证码输入，不调用发送接口，不提交伪造验证码，注册页提示物业核验及审批。后端必须按真实短信开关独立执行校验，前端能力开关不授予绑定权限。原小程序及 App 的短信行为不在本次修改范围。
- 已有账号的“绑定业主”页沿用同一短信能力控制；没有定位缓存时仍可手选地区，小区地址控件已正确注册。绑定业务拒绝不再因 HTTP 200 被误判为成功，表单输入与提交不再向浏览器日志打印姓名、身份证、手机号或验证码。个人中心“我的房屋”改用共享房屋查询，增加加载、失败重试及旧响应丢弃，避免查询错误后白屏或显示旧房产。

## 验证

在 `wuye-xcx2/WechatOwnerService-v0.8` 执行：

```powershell
npm test
npm run build:h5
```

本轮新增回归先观察到预期失败，再修复；现有及新增合计 63 项 Node 测试通过。H5 编译成功，原入口包约 295 KiB，有构建体积提示。真实 Edge 浏览器以 360、390、430 像素宽度打开编译后的登录、注册及已有账号绑定页，确认短信入口隐藏、审批提示可见、没有横向溢出和 JavaScript 异常、支付关闭；没有业务写入。私有截图及浏览器结果保存在 `.runtime/nonpayment-register-*.png`、`.runtime/nonpayment-binding-*.png` 和 `.runtime/nonpayment-h5-smoke.json`。

多房产竞态、错误与会话回归使用合成响应，不代替正式号手机多房产、首次注册审批、真实通知或实际微信授权过期后的完整验收。服务器部署与后端注册短信开关修复由本轮其他任务分别记录。
