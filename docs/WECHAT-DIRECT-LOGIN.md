# 微信直接登录与房产验证

2026-11-03，按用户确认的规则实现：微信登录不需要审核，三项业主资料完全匹配后立即绑定。

## 业主操作

1. 关注正式服务号，点击服务号菜单进入 https://h5.jiaanfuwu.cn/ 。联调入口仍保留访问码。
2. 微信内自动完成公众号网页授权；未绑定时可进入首页和“我的”，房屋与账单显示绑定提示。
3. 点击“绑定房产”，填写物业登记的姓名、手机号、身份证号。三项必须同时匹配同一条有效业主记录。
4. 匹配成功后立即查看该业主名下房屋及已发布账单，不需要注册、设置密码或等待审核。
5. 同一业主记录下的多套房屋自动显示；另一条业主记录通过“继续绑定房产”单独核验，随后在房屋页切换。通知指定的 roomId 在已核验绑定中定位，找不到时停止查询。

三项资料缺失、错误或存在多条候选记录时，页面提示联系物业核对，不公开哪项命中。物业须事先完善真实业主资料及房屋关联。本轮只提供公众号已配置单小区的界面，跨小区选择尚未实现。

## 权限与兼容

未绑定身份只在 Redis 保存短期微信身份凭据，不创建普通用户，也不签发业主 token。绑定成功才在原订单事务中建立技术账号及已通过绑定；服务端根据微信凭据确定身份，不采信浏览器提交的 OpenID 或审批状态。失败尝试限流，重复绑定幂等，锁保持至订单事务完成。

OAuth 使用一次性短期票据，URL 不包含 OpenID、身份证或业主 token。新绑定接口和公共日志不记录整包个人资料。房屋及账单仍由后端校验归属，前端切换不扩大权限。

原账号密码和小程序接口保留旧审批限制，历史待审记录不会因微信登录自动放行，须重新通过本次三项核验。H5 的旧登录、注册链接引导至微信流程；电脑普通浏览器提示在微信打开。

## 运行和验收

本轮运行沿用正式域名入口、本机 Java/数据库及 SSH 隧道，电脑必须在线。支付、定时出账和自动通知继续关闭，没有自动向真实业主发送消息。

本地验证使用随机隔离房产和合成微信身份，对真实运行服务测试绑定、房产权限、已发布账单查询；合成票据不能证明真实手机首次 OAuth 已通过。手机验收应使用尚未绑定的微信，从正式号菜单进入，依次测试错误资料拒绝、正确资料立即绑定、房屋及账单归属，再使用另一条真实业主记录验收继续绑定和切换。无需在聊天里提供身份证或密钥。

验证命令及隔离测试工具见实施计划和 `scripts/simulation/wechat_direct_flow.py`。隔离资料结束后必须使用工具的 cleanup 删除并比对原业务表快照，不手工宽泛清理业务表。
