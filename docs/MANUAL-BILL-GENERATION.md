# 手动生成待审核账单

2026-11-04：已补齐物业后台的手动出账入口，并在当前本机运行服务中部署。新增费用写入 `pay_fee`，不会直接成为审核列表读取的 `bill`；此前自动任务关闭，且任务配置没有覆盖一次性费用类型 005，因此用户新增费用无法进入审核及推送流程。

## 物业操作

1. 打开后台「费用管理 → 费用账单」，点击「生成待审核账单」。
2. 按名称或出账类型查询，选择当前小区的收费项目。项目较多时可以翻页。
3. 点击「确认生成待审核账单」。按该收费项目整批生成符合条件的欠费明细；支持 001、002、003、005，金额由原服务端规则计算。
4. 核对金额、欠费清单及业主信息后，点击「审核并推送」，H5 发布与公众号通知一次提交。
5. 查看「通知状态」；有明确可重试的失败时点击「重试失败通知」，个别业主补发仍可进入「欠费清单」。

生成入口只生成草稿，不自动审核、发送公众号消息或启用定时任务；后续审核按钮已合并通知，详见[审核与通知合并说明](REVIEW-AND-NOTIFY.md)。重复生成返回当期已有账单及状态，保留已审核、已通知的原快照；没有可出账明细时提示原因，不保存空账单。新增费用不会自动追加到已经生成的当期快照，需先核查现有账单。
