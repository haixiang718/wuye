# 自动出账与账单审核

2026-11-06 起，新增有效应缴费用会自动生成待审核账单，包括实时出账（004）。日常操作不再需要先点“生成待审核账单”。

## 物业操作

1. 在房屋收费创建费用，或通过批量创建、抄表、导入等入口产生应缴费用。
2. 进入“费用账单”查询。房屋创建接口会在保存后尝试生成，其余事务提交事件通常数秒内处理。相同收费项目的费用按批次汇总，明细全部保留；新增费用产生独立补充草稿，不改原单。
3. 黄色为待审核，核对明细后选择“审核并推送”或“审核不通过”。不通过必须填写原因，显示浅红色。
4. 审核通过显示绿色，H5 可查，并按原流程处理公众号通知。审核不通过和重新提交均不发送通知，也不能在线支付。重新提交保留原单金额与明细，需再次人工核对审核。

账单审核颜色与房屋收费缴费颜色含义不同：房屋绿色表示无欠费，账单绿色表示审核通过。

页面顶部会显示自动出账排队、异常待重试和等待数量；状态读取失败明确提示刷新核对。资料缺失时修正业主、房屋或计费资料，系统保留事件重试。必要时可在“更多操作 → 重新检查出账”发起检查，正常流程不依赖该按钮。

## 计费与防重

- 001/002/003/004/005 全部经过草稿与人工审核；004 不再绕过审核。
- 尚未开始计费、预缴到未来、无正应缴金额的费用等待到期检查，不创建空账单。
- 费用事件和费用行在同一数据库事务提交；回滚没有幽灵事件。队列版本与租约防止并发丢事件和重复确认，服务重启可继续处理。
- 一笔资料异常不会阻止同收费项目其他正常费用送审；异常部分仍保留重试。
- 不因跨账期而覆盖待审核、已驳回或未结清原单。已缴某户可以生成下一计费区间的补充草稿，不被其他户欠费阻塞；防重核对费用和冻结计费区间。
- 原有滚动账期计算暂时保留，客户最终出账日和账期仍需业务确定；队列每天重新核对费用是否到期，不擅自改变计费单价或周期。
- 合同费用要求关联本小区真实业主，无法关联时保留异常，不伪造收件人。

## 部署

先备份数据库和 API/business/job 运行包，执行 `python scripts/migrate_automatic_bill_review.py --apply`，再构建这三个服务及依赖，更新后台静态文件并重启。

迁移新增 `automatic_bill_queue`（持久出账队列）与 `bill_review_record`（不可更改的审核审计）。费用新增/关键计费日期变化在事务内写队列；审核状态变化在同一事务记录审计，禁止非法状态转换或修改/删除审计。迁移不改原财务行，现有有效费用只补录队列。工具重复执行会核验已有触发器定义，不覆盖不兼容定义。

`java110.billing.autoReviewEnabled=false` 可停用新增的草稿处理线程。该线程与旧催缴/出账计划任务独立，只生成草稿，不审核、不通知、不扣款；其他定时任务继续按原配置停用。队列等待期间不能清理队列表或任意修改版本/租约。回退旧 JAR 可保留增量表和审计；不要删除已产生的账单快照。
