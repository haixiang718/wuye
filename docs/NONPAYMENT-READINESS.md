# 非支付流程完善记录

日期：2026-11-03。商户号尚未开通，在线支付保持关闭。本轮完善现有业务及运行工具，不将联调入口描述为整套系统已部署云端。

## 已完成的业务改进

1. 修复快速切换房产时慢响应覆盖新房产费用、业主查询失败后页面等待不结束、请求头合并及登录业务错误处理。
2. 补齐登录过期清理与重新授权；允许登录后返回原房屋账单，返回路由有白名单、时限且只用一次。后端仍逐次验证房产归属。
3. 当前短信服务明确关闭时，注册和绑定改为提交资料后由物业审核，不再要求不存在的验证码；短信开启或配置不明时，后端仍要求验证，前端开关不能绕过。已有业主信息必须匹配，申请状态仍为待审，审核前不能登录查账。
4. 正式号只读检查工具 `python scripts/wechat_readiness.py` 可检查凭据、模板字段和菜单，不发布菜单、不发送通知，也不输出密钥或 OpenID。正式号现已添加“物业费用账单缴纳提醒”，人工推送已适配其五个字段并保存小区配置；真实收件仍待验证，详见[正式号账单模板](OFFICIAL-BILL-TEMPLATE.md)。

H5 改动和测试详见 [H5 专项记录](NONPAYMENT-H5.md)。无短信的人工核验方案需要物业核对申请人的真实身份及房产权属，不能仅凭注册申请自动放行。

## 出账与审核复测

在真实本地服务创建随机标记测试资料，以不包含短信验证码的注册请求走公开 H5 后端入口，验证：待审批禁止登录、后台人工审批、出账生成草稿、草稿对业主隐藏且不能推送、后台审核发布、H5 查询冻结金额及欠费详情、模拟通知防重复、通知后仍未缴费。

本轮未调用真实消息发送接口、未伪造微信支付回调，也未向正在运行的业务库写入伪造缴费流水。测试后清理该批资料，15 张原业务表行数及摘要与执行前一致；订单审计保留。通知身份和传输为替身，此结果不能代替正式服务号手机收件验收。
