# 正式域名与公众号联调入口

用户已确认：使用现有阿里云 2 核 2GB 服务器提供正式域名和 HTTPS 入口，业务与数据库继续在本机运行，通过加密隧道连接。本阶段用于联调，不承诺电脑离线时仍可用。

公网服务器为 `118.31.186.6`，域名为 `jiaanfuwu.cn`，ICP备案已通过。`h5` 承载业主入口，`wx` 承载微信回调；`admin` 先解析但默认拒绝公网访问，管理后台仍在本机操作。三个主机记录均使用 A 记录指向服务器公网 IP。

服务器只安装 Nginx、证书工具与 SSH 隧道所需配置，不部署数据库或六个 Java 应用。Nginx 将请求转发到服务器回环地址 `127.0.0.1:18080`；本机 SSH 反向隧道将该端口连接到本机受限公众号网关 `127.0.0.1:8080`。公网不暴露业务端口或数据库端口。隧道使用单独的密钥与账户，并限制为远程转发指定回环端口。

首次部署先检查服务器系统、已有站点、磁盘和权限，备份可能修改的配置。DNS 生效及 80/443 可达后签发证书，校验 Nginx 配置再重载。微信校验文件通过独立静态目录提供，只接受 `MP_verify_*.txt` 名称；微信公众号 AppSecret 和 SSH 密码仅保存在 Git 忽略的本机运行目录中。

复用已有受限公众号网关、H5 与后端身份绑定流程，保留联调访问码及支付关闭状态。正式域名联通后核实当前服务号模板权限，再按账号配置开展授权、两名业主数据隔离与后台账单查询验证。菜单发布、发送真实通知和支付另按用户具体操作验收，不自动群发或触发支付。

验收分层记录：域名解析、SSH 登录、HTTPS、隧道、H5 及回调签名可以由工具检查；微信后台配置保存和手机 OAuth 结果需要用户操作后核对。测试号绑定不能直接作为正式号身份。电脑或隧道离线时入口应返回明确的临时不可用响应，不出现假成功。
