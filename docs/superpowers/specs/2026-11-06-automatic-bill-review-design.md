# 所有应缴费用自动进入审核

用户要求：创建应缴费用后自动出现待审核账单，不依赖手工生成；实时出账也需要审核；新增审核不通过；待审核黄、审核通过绿。

沿用费用记录、不可变账单快照、审核发布和付款回写结构。费用创建、批量导入均通过数据库事务内写入出账队列，后台持续处理，失败保留并重试；房屋收费创建成功后主动尝试生成，服务故障时队列接管。自动任务只生成草稿，不发送消息、不扣款。将 004 纳入现有快照计算与防重，周期按月组织，实时指费用自动送审，不是跳过审核。

队列按小区和收费项目合并事件，带版本、租约、失败提示及重试时间。所有有效收费类型均纳入；数据库提交后才可消费。已有有效应缴费用一次性补录队列，不重写历史已审核和已支付快照。尚未到计费时间、零应缴或缺业主资料不能伪造可付款账单；队列等待或记录异常，保留重试。

审核状态：DRAFT（黄色）→ PUBLISHED（绿色），或 DRAFT → REJECTED（浅红色，原因必填）。驳回不能推送或在线支付，不自动覆盖、自动通过；员工可明确重新提交同一快照后审核。数据库条件更新控制并发，记录审核和重提审计。账单审核颜色与房屋缴费颜色含义独立。

保留现有手动生成接口供修复重试，正常页面不再要求人工生成。H5 和在线支付继续只接受已审核快照。每种写入路径通过数据库事件统一覆盖，自动工作线程不启用原催缴、通知定时器。

验证：先写并运行失败测试，再实现 004、防重、队列事务/重启恢复、驳回/重提、越权及并发审核、H5支付隔离；回归原出账、支付和通知，浏览器验证行色及操作。备份数据库与运行包，再更新运行服务；只生成真实待审核草稿，不代替用户审核、推送或支付。
