# 管理后台 A 方案：简洁蓝白

用户于 2026-11-03 在本地对比预览中选择 A 方案。本文件记录已确认的方向，直接用于实施和验收。

## 目标与范围

将现有 Vue 2 / Bootstrap 管理后台统一为深蓝导航、蓝色主操作、浅灰背景及白色卡片。覆盖公共导航、页面标题、卡片、按钮、表格、分页、输入框、下拉框、日期选择器及弹窗；账单列表是重点示范页面。沿用现有菜单、权限、数据和事件绑定。H5、登录页、支付和公众号接口不属于此次视觉改动范围。

## 实现

新增 `public/css/admin-blue.css`，只通过 `admin.html` 引入，所有选择器限定在 `body.admin-blue` 下。使用 CSS 变量统一色彩与间距，不引入依赖、字体下载或主题切换脚本。保留原侧栏宽度和折叠机制，避免破坏旧框架的高度计算。宽表格在卡片内容中横向滚动，保留菜单浮层、日期和下拉控件的可见性。

账单页为查询字段补充可见标签，为审核状态增加带文字的色块，将金额右对齐，并显示简短流程说明。名称和编号在同一列分行显示，金额单位集中标注，操作列固定在表格右侧。保留真实字段及事件，不将预览样例数据带入实际页面。

费用配置的新增、修改弹窗沿用真实字段和条件显隐；统一表单、标题和按钮样式。将原显示文字“催缴类型”改为“出账规则”，为缴费周期标明月份单位，在新增表单补充出账规则说明；取消按钮改为中性白色。不调整计费规则或有效期。

## 验收与回退

浏览器使用本机真实管理会话，检查账单查询、欠费清单、费用配置新增/修改弹窗（打开后取消）、日期选择器、小区切换菜单，以及导航展开/折叠。检查 1440 和 1024 像素视口，宽表格只在内容区滚动。通过现有前端测试并检查新增脚本错误；不审核发布账单、不发送通知、不保存业务表单。

删除 `admin.html` 的主题样式链接及 `admin-blue` 类即可回退公共主题；账单页标签和状态文字保留原业务含义。

## 验证结果

2026-11-03：现有前端测试 12 项通过；真实本地浏览器检查 13 项通过，包括账单查询与清空条件、两种桌面宽度、侧栏折叠及浮出菜单、小区下拉、欠费明细、费用新增弹窗和日期浮层、修改弹窗、业主与房屋列表。无新增 JavaScript 错误或 HTTP 错误，检查未发起业务写请求。

本次没有逐页验收所有保留模块，也没有验证收费保存、账单审核或公众号发送；这些仍沿用现有逻辑。截图和检查记录保存在本机 `.runtime/ui-preview/`，不提交含业务信息的截图和会话。
