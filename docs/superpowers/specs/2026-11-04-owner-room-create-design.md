# 新增业主时同时绑定多套房屋

用户要求简化后台录入，已选择“一次可选择多套房屋”。在现有添加业主弹窗加入房屋查询、勾选、已选清单和移除操作；一次提交保存业主与全部关系。不新建房屋，不自动收费，不关联微信身份。微信用户仍需三项资料匹配后认领。

房屋必须是当前小区已建档且未绑定的有效房屋。选择房屋时，姓名、手机号、身份证号须完整；同小区同身份证的已有业主应通过现有追加绑定流程处理，避免重复档案。允许不选房屋，仅录入资料，以兼容原流程。家庭成员、租客不显示房屋选择。

复用 owner.saveOwner 和原订单业务，业主及房屋关系在一次订单提交中处理。新增服务校验多房参数、同小区可绑定条件；提交前使用 Redis 对业主身份及所有房屋加互斥锁，再检查可用性。按钮防重复提交，失败保留填写内容。原单房 roomId 调用保持兼容。

验收覆盖：多房、重复选择、非本小区或已绑定房屋、重复身份、锁冲突、失败时不落部分关系、成员兼容、真实浏览器新增及房屋查询、H5 身份核验回归。仅使用隔离测试资料；不发送消息、不收款。
