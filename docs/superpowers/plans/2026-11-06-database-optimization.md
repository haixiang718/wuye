# 数据库结构优化实施计划

- [x] 复核当前表结构、账单编号重复值、InnoDB 聚簇索引及索引提示引用。上一轮 7 个索引已存在，无须重复创建。
- [x] 为 bill.bill_id、bill_owe_fee.owe_id 增加主键；要求原列非空、无重复，无已存在的不同主键；将同目的旧身份查找索引退役。

- [x] 新迁移默认仅输出计划，执行前完成两库备份和校验，生成逆向 DDL；同名不同结构、索引提示/外键依赖、重复或空编号均拒绝执行。增加幂等、失败保护、回退与数据校验测试。
- [x] 安排短暂业务服务维护窗口，执行已经验证的 DDL、更新统计信息，核对业务及财务数据，恢复服务并运行付款数据库与健康检查。
- [x] 记录前后执行计划、索引数量及备份回退位置，提交并同步 GitHub。
