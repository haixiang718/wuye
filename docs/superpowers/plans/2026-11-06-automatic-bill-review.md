# 自动出账与审核实施计划

**目标：** 所有已产生的正金额应缴费用自动成为待审核账单，含实时出账，支持驳回与重新提交。

**实现：** 复用 GenerateBillProTemplate 和 BillSnapshotService。事务内数据库队列覆盖所有 fee 写入，job 专用工作线程按版本与租约消费，房屋创建后同步尝试；审核走原 fee.reviewBill 路由的明确 action，SQL 条件更新及审计。
