# 业务修复实施计划

> **For agentic workers:** Use superpowers:executing-plans to implement task-by-task.

**Goal:** 修复已复现的账单生成缺陷，核验业主绑定和数据权限，处理保留业务中的账户和合同缺口。

**Architecture:** 保留现有费用计算口径及 merged 部署。任务服务先计算完整账单，费用服务在单个本地数据库事务中锁定收费配置、复查周期、保存汇总和明细。绑定和权限修复以服务端可信身份为准，避免仅靠 H5 或公网白名单保护。

**Tech Stack:** Java 8、Spring 事务、MyBatis、MySQL、现有 Python/Java/Node 验证工具。
