# 房屋收费状态提示

房屋收费列表移除“催缴单”（含批量入口）和“人工托收”，保留批量创建、欠费缴费、查看费用。

列表增加整行颜色、文字状态和图例：

- 浅黄色：存在未缴费项。任一房屋费用按现有欠费计算有正余额，或任一账单快照仍有未缴余额，即显示此状态。推送通知不会使账单变成已缴费。
- 浅绿色：账单结清，表示有费用记录且当前无欠费，包含已预缴至未来的费用；不代表未来无需继续缴费。
- 无底色“暂无费用”：没有费用或账单记录。
- 无底色“状态待确认”：查询、金额或日期异常，不误报结清；有确定欠费时优先显示未缴费。

沿用房屋列表已有的小区与员工授权。只按当前页房屋 ID 批量读取费用与账单，SQL 使用绑定参数，不逐房屋发起额外 HTTP 请求，不修改支付或账务数据。正常查询、重置、翻页及刷新都会重新取得状态。
